        How to use the planner

        1. Place points. With a Path step selected, click on the field. The path starts where the robot is and curves through each point.
        2. Shape it. Drag points to move them. Select a point to show its curve handles; drag a handle to set the heading there and how wide the curve is.
        3. Set speeds. Select a point to set the speed limit and direction of the section that ends at it. The path colour shows the planned speed: blue is slow, red is fast.
        4. Run. Press Run simulation. vexsim drives the robot with mclib's C++. Each step is checked against its target.
        5. Export. Save keeps the routine as JSON. Export C++ gives the autonomous() code for the robot.
